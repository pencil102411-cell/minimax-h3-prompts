# MV 实战记录：《Red Line》（2026-10-28 ~ 10-30，本工作站，一百多条）

一支四人女团风说唱 MV，全片的人物镜头基本都用 H3 跑。下面是批量实战里验证过的规律，写提示词前对一遍。

## 跑法和设置

- **参考生视频 = 设定图 + 首帧图（MJ 分镜图）+ 这句原曲**，5 秒一条，只跑一采（REF2VA int8 + ref2v 4 步 LoRA，6 步 euler），1152×640，约 50 秒一条。唱段、看镜头、甩头、手势都用它。
- **没有成员脸的镜头**（脚、车、人群远景、物件）：首帧生视频（FL2VA 8 步），只给首帧图，不挂设定图。
- **只用一采**：同尺寸二采（Refine 0.2）让画面变脏、脸上出鳞片纹、后排人脸变歪。不用 SeedVR2 放大（人会变形）；要 1080P 用 Topaz 这类不改脸的传统放大。
- **一条一刀**：30 秒一条排 12 个镜头，顺序被打乱，原曲复用只撑了开头约 2 秒，之后是模型自己编的音乐。15 秒排 6 个镜头那几条稳定、原曲复用正常；要卡拍、对口型的正式素材，一条一刀、5 秒最稳。
- **种子差别很大**：同一条 5 秒，原曲复用的包络相关从 0.47 到 0.99 都有，偏差集中在后半段。对口型跑 2 个种子挑。

## 参考图

- **四栏设定图（脸部特写 + 正 / 背 / 侧无脸全身）整张直接挂就行**：衣服、帽子、配饰全对，不会生成无脸的人。（参考控制第 3 节"最好拆开用"是更早的推测，本片整张挂没出问题。）
- **首帧图的构图会被照搬，脸不会**：MJ 分镜图里那张替身的脸不会带进视频，脸以设定图为准；但它的景别、站位、背景几乎原样照搬。提示词写明"<Picture 2> 只提供构图、光和背景，图里的人只是替身"。
- **首帧图就是开场**：给半身图，前 1.5 秒就是半身、低头、闭嘴，2 秒才推近开始唱。首帧图要已经是目标景别、动作开始前的姿势。
- **正顶俯拍**：只给空的俯拍场景 + 设定图，会照设定图的正面站姿出成正面全身；给一张"已经有四人、从头顶往下看"的画面当开场构图，才一直保持正顶俯拍。
- 首帧图里自带的东西去不掉：图里人戴了一副眼镜，提示词写"脸上不戴眼镜"也没去掉。要去就先改图。
- 场景图里的招牌会变成乱码字块；首帧图先把字擦掉。

## 提示词

- **近景别写地面**：写了"站在地上的红线里""地上的灯从下往上照"，三条都拉成全身远景再慢慢推近（参考控制第 2 节当时的推测，本片验证了）。去掉地面描写、加一句 `The first frame does not show the floor; the camera never pulls back to a wide view.` 才直接推到近景。
- **"full body" 会拉得太远**，脸小、易变形。要到腰、到膝盖就写到腰、到膝盖。
- **动作时间普遍晚 0.5~1.5 秒**：写 1.7 秒踩进水洼，实际 2.7 秒。入点按实际动作挑，提示词里的时间可以提前写半秒到一秒。
- **接了原曲，敲击类动作会跟着歌词字走**（敲麦只比 "tap" 晚约 0.1 秒）。要卡音乐的动作就接原曲。
- **原曲可以提前截**：想让某句唱在推近之后，把原曲起点往前多截一两秒，让那句落在第 2~3 秒。
- **群众要写表演**：只写"排队的人"，所有人死盯镜头、不动；写成"交头接耳、有说有笑、不看镜头""一个接一个把手机举起来对着画右拍"才对。
- **走路写朝向**：只写"四人往前走"出过倒着走。写脸朝哪、往哪走、离镜头越来越近还是越来越远。
- **人和道具的互动不可靠**：首帧生视频里写靴子推倒铜柱，结果靴子没有推的动作、铜柱自己倒了。
- **人入画别用首尾帧逼**：尾帧有人、首帧没人，人会凭空浮现。首帧就让她以剪影出现在门缝 / 远处。
- **写死"正常速度"**：不写时偶尔自己出慢动作。
- **舞蹈写成真的在跳**：写膝盖弹、左右换重心、甩手臂、甩马尾，四人真的跳起来了（动作是它自己编的）。站桩的问题是在灰豆 Seedance 上出现的（多参考生成不写动势、动作迁移只写"严格保持"时），H3 这样写没站桩。
- **模型会自己切一刀**（比如突然切到脸部特写），常在 2~3 秒。用不到就避开那段。
- 素材第 0 帧和第 1 帧之间常跳一下，剪辑时入点从 0.05 秒以后开始。

## 工作站

- 连跑三十多条后出过 "CUDA error: unknown error"，队列卡在 running 0 / pending N 不动，要重启 ComfyUI；也出过整台断网。任务不动时先查 `/history/<id>` 的报错。
- 冷启动第一条要 4~8 分钟，之后每条 5 秒约 50 秒。
