# 本地参数与取舍（本地工作站，RTX 5090 32GB）

## 官方默认值

| 项 | 官方值 | 说明 |
|---|---|---|
| 分辨率 | 短边 768，16:9 即 1344×768 | 模型就是按 768p 训练的。官方的 2K 是另一个没开源的模块（Regenerate-2K）重新生成出来的 |
| 帧率 | 24 fps | |
| 时长 | 4–15 秒 | 帧数要等于「17 的倍数 + 5」：124 帧≈5 秒，243 帧≈10 秒，362 帧≈15 秒 |
| 步数 | 官方推理框架 SGLang 默认 50 步；ComfyUI 官方模板 20 步 res_multistep | |
| CFG | 1（用 BasicGuider） | 官方发布的权重已经做过 CFG 蒸馏，不需要负面提示词 |
| shift | 视频 12，音频 3 | |
| 参考图尺寸 | 短边放到 2048（对应节点里的 `max`） | ComfyUI 节点默认是 `match`，会把参考图缩到和生成画面一样大 |

## 和「油感、贴图感」可能有关的设置

以下几点是按官方资料推断的。其中第 2、3 点已在本工作站上做过同种子对比（2026-10-28，A 独唱·粉色宫殿，6 步，1280×736，2 个种子）：
- **提示词格式**：换成官方格式后，脸明显更自然，有效。
- **参考图 `max`**：和 `match` 比差别不明显，但更慢。

其余几点还没验证。验证时一次只改一项，用同一个种子对比。

1. **分辨率超出训练范围**：1920×1088（1080P）比 768p 大了一倍多。社区普遍认为约 0.8MP（1216×672）是消费级显卡上的实用上限。想要 1080P 成片，更稳的做法是用 1344×768 或 1280×736 生成，再用外部工具放大——但别用 SeedVR2 这类生成式放大（实测人会变形），用 Topaz 这类不改脸的传统放大；也别接同尺寸二采精修（实测画面变脏）。见 [MV 实战记录](mv-field-notes.md)。
2. **参考图被缩小**：`ref_image_size = match` 会把参考图缩到和生成画面一样大。三视图设定图里，脸只占画面一小块，再一缩，细节就没了，模型只能自己脑补，脑补出来的脸往往很「AI」。改成 `max` 会慢一些，因为参考图的信息每一步都要参与计算。
3. **提示词格式**：用官方英文分段格式写，见 [官方格式要点](official-format.md)。
4. **素材本身**：三视图的灰底和平光、CG 感重的场景图，都会把成片往贴图、CG 方向带。处理办法见 [参考控制](reference-control.md)。

## 步数、速度和纹理

本工作站已有的实测数据（参考生视频，10 秒）：

| 设置 | 分辨率 | 每段耗时 | 画面 |
|---|---|---|---|
| 官方 25 步 res_multistep，不加速 LoRA | 1280×736 | 约 510–530 秒 | 快动作也干净 |
| LightX2V 4 步加速 LoRA，用 6 步 euler | 1280×736 | 约 156 秒（2 张图），约 178 秒（5 张图） | 抽查快动作帧是干净的，但之前出现过划痕状纹理 |
| 同上，参考图尺寸选 `max` | 1280×736 | 约 212 秒（2 张图） | 和 `match` 差别不明显 |
| 同上 | 1920×1088 | 约 535 秒 | 缩小看画面正常，开场仍先给全身镜头（用的是旧写法） |
| 4 / 6 / 8 步各种加速 LoRA（ref2v 4 步、8 步，larry turbo） | 1280×736 | 111–186 秒 | 动作越快纹理越明显，根源是加速 LoRA 本身 |

可以试的提速办法，都**未在本工作站验证**：

- **comfy kitchen attention**：用 `ModelAttentionBackend` 节点，`attention` 选 `comfy kitchen attention`，工作站上已经有这个节点。社区在 RTX 5090 上实测，采样阶段快了约一倍，人脸相似度和口型没变化。适合「20–25 步质量档」提速，也可以和现有的 Sage fp8 补丁对比一下哪个快。
- **把宽度从 1280 降到 1216**：解码时切的块从 28 块减到 24 块，整体快约 15%（社区在 5090 上测的）。
- **Spectrum 加速节点**：会跳过一部分计算，属于有损加速，画质要求高时不用。
- **先低配出小样**：用 6 步、低分辨率先看动作、调度和口型；确认提示词没问题后，再用 20–25 步出成片。注意，步数不同时，即使种子相同，画面也不会一样，小样只能用来检查提示词。

加速 LoRA 的已知副作用（社区测试结论）：
- 长音、气声会变弱。
- 中英混唱、口音会变得平淡。
- 硬切会被抹成叠化。

## 其他

- 参考图的数量上限：图片 9 张、视频 3 段（每段 2–15 秒）、音频 3 段，合计最多 12 个文件。
- 15 秒以上要分段生成再接起来；超过这个长度，人物容易变样。
- 生成过程中不要频繁查询 ComfyUI 的状态接口。社区实测这样会让采样卡住 18–43 秒，查询间隔放到 20 秒以上。
